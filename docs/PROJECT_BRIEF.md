# Project Brief: djphelix.com

## Purpose

Build and maintain the official website for `djphelix.com`.

## Current phase

The project is in its repository-foundation phase, and the site is currently under development.

## Current scope

- Preserve a clean, framework-neutral starting point.
- Reserve `src/` for future website source files.
- Reserve `public/` for future public assets.
- Document decisions before introducing implementation-specific tooling.

## Deferred decisions

- Site architecture and content structure
- Visual design and brand system
- Frontend framework or static-site approach
- Hosting and deployment workflow
- DNS configuration

Deployment and DNS configuration will be added later, after the relevant design and implementation decisions are made.

## Security and licensing

Secrets, credentials, API keys, and local environment files must not be committed. No license is included at this stage; licensing should be selected explicitly if the project's distribution requirements change.
