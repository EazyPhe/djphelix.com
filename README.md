# DJ Phelix Website

This repository contains the official website for `djphelix.com`.

## Status

The site is currently under development. Deployment and DNS configuration will be added later.

## Repository scope

This repository is a framework-neutral foundation for future design and development decisions. No frontend framework, build system, hosting provider, or deployment workflow has been selected yet.

## Structure

- `docs/PROJECT_BRIEF.md` documents the initial scope and deferred decisions.
- `public/` is reserved for future public assets.
- `src/` is reserved for future website source files.
